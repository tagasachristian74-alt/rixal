Paano laruin?

Isang game lang, pero infinite — mag-shuffle ang 200+ questions hangga't gusto mo. Walang timer, ikaw lang vs. utak mo.

  • Identification: i-type ang sagot. May Hint button — 4 choices (1 tama, 3 mali).
  • True or False: pindutin TRUE o FALSE. Sobrang tricky ang statements.
  • Matching: piliin ang tamang definition ng term. Mahirap ang choices.
  • May score, streak, accuracy. Sa dulo, makikita mo lahat ng mali mo para ma-review.

Tip: basahin muna ang explanation pagkatapos ng bawat sagot — dun ka pinaka-mabilis mag-memorize.

Focused button = Identification + True/False + Matching, pero 3 files lang ang laman (Final Journey + Return to Europe/El Filibusterismo + Hong Kong/Dapitan). Walang halo from Life/Works PDF.
